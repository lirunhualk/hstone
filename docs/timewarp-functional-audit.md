# 时空扭曲随从逐卡审计

本次范围为老旧的烛台关联的 66 张时空扭曲随从，加上肖像生成的跳蛙骑士和诗心龙，共 68 张。卡牌版本继续固定在 HearthstoneJSON build `247416`、补丁 `36.0.3`；此次修复不更新卡池版本，也不修改生成快照。

普通与金色牌面来源为 [固定饰品快照](../lib/game/generated/battlegrounds-trinkets-36.0.3-247416.zhCN.json) 的 `timewarpCostTwoMinions`：小型 25 张、等级 3；大型 41 张、等级 5。跳蛙骑士和诗心龙另见 [随从注册表](../lib/game/content.ts)。以下列出普通 CardID；这 68 张的金色 CardID 均为对应普通 CardID 加 `_G`。表内整理原始文案的换行与空白，保留数值、对象、时限和金色重复语义。

上一轮已接入 28 张烛台随从，诗心龙为既有实现。本轮补齐剩余 38 张烛台随从和跳蛙骑士：当前 66 张烛台来源及两张肖像随从均有完整规则，普通/金色身份和原画继续沿用固定快照。

本轮专项覆盖招募行为、战斗事件、真实生成与共享池、满手/满场、普通/金色、成长向量、永久写回、幽灵隔离及存档恢复。统一入口为 `npm run test:timewarp`；具体文件见[招募专项][recruit]、[战斗专项][combat]、[支持专项][support]、[剩余招募专项][remainingRecruit]、[剩余战斗专项][remainingCombat]、[招募边界专项][recruitBoundaries]、[事件边界专项][eventBoundaries]和[存档专项][saveCompat]。逐卡状态说明实现路径与验证边界；最终发布仍须完成仓库的全量检查。

## 可玩与存档

- 完整来源注册表保留全部 66 张烛台随从，继续用于固定构建数据校验、原画和旧存档读取。
- 新烛台发现候选经过 `FULLY_SUPPORTED_TIMEWARP_CARD_IDS` 与完整支持标记，再按本局可用类型过滤和确定性抽取；66 张均已恢复候选资格，满手与候选不足沿用共享发现路径。
- 跳蛙骑士肖像 `BG35_MagicItem_870` 已恢复新局饰品候选；诗心龙肖像 `BG32_MagicItem_364` 保留。两者仍遵守原有种族和英雄技能可用性过滤。
- 存档继续兼容 v52：既有实体保留属性、身份、池所有权与成长/额度计数，载入刷新动态数值及剩余次数文案。继承亡语的可选 `count` 缺失时按一份兼容，非法数量及不允许的亡语来源不被接纳。`timewarp*` 成长和次数计数在载入边界要求安全的非负整数，畸形值归零，有效进度继续保留。
- 永久野兽军团属性作为可选玩家账本向旧存档补零；十种合法种族值、完整开放种族列表和新生成实体都接受存档校验。玩家与 AI 使用同一规则，训练观察只暴露受控玩家的账本和能力数量，不包含对手隐藏状态或内部实例 ID。

## 复核要点与成长证据

1. **触发与向量分开。** 钩尾、佩吉、合唱鱼人和劫掠者的金色是两次完整触发；电荷金刚产生两个独立 4/4 附件，地卜师的金色仍只获得一张宝石。
2. **永久与本场分开。** 黏冻大肚怪、帝国之手、滑油机器人、食尸卡布拉和狂棍野猪人显式写回永久增益；小野猪和暮喉龙按普通战斗增益处理，诗心龙等保留规则另行结算。战斗复制、变形与幽灵不覆盖无关招募实体。
3. **观察真实事件对象。** 受攻击在伤害前派发，受伤要求生命损失，圣盾吸收仍会派发失盾；吞食、购买、复生、磁力和属性转发都读取实际实体，失败动作不伪造成功事件。
4. **保留重复数量。** 飓风机甲和跳蛙骑士使用可计数的继承亡语记录；同来源多份能力不会被去重。复制、提图斯重复和主动触发逐个进入亡语观察链。
5. **独立处理容量与所有权。** 亡灵造物和对手复制的召唤/入手各自检查满场/满手；伙伴、生成副本及磁力附件不制造普通池所有权。共享池守恒需同时计入所有玩家持有的报价和实体。
6. **成长按完整牌面向量。** 画家每个合法低等级出牌增加 +3/+2，丛林狮王每个法术增加 +4/+3，增强幼龙每次回合结束增加 +5/+5，基尔加丹每次回合结束增加 +7/+7；金色分别翻倍。计数跨回合与存档保留，动态文案从基础牌面重算，避免重复载入再次放大。

画家的[暴雪论坛原始实战报告](https://us.forums.blizzard.com/en/hearthstone/t/timewarped-painter-never-triggers-before-futurefin/156211)记录旧版 +2/+1 效果从 35/30 到 57/41 的 +22/+11 增益，支持按整组基础向量提升；固定构建将其基础数值更新为 +3/+2。丛林狮王的[原始实战视频约 42 秒](https://www.youtube.com/watch?v=fhluig0KhT8&t=42s)展示 “Law of the Jungle +60/+45”，与十五组 +4/+3 一致。两者的攻击/生命比例均排除每次只增加相等 +1/+1 的实现。固定构建普通/金色初始数值仍以牌面快照为准。
