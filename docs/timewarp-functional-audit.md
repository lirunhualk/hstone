# 时空扭曲随从逐卡审计

本次范围为老旧的烛台关联的 66 张时空扭曲随从，加上肖像生成的跳蛙骑士和诗心龙，共 68 张。卡牌版本继续固定在 HearthstoneJSON build `247416`、补丁 `36.0.3`；此次修复不更新卡池版本，也不修改生成快照。

普通与金色牌面来源为 [固定饰品快照](../lib/game/generated/battlegrounds-trinkets-36.0.3-247416.zhCN.json) 的 `timewarpCostTwoMinions`：小型 25 张、等级 3；大型 41 张、等级 5。跳蛙骑士和诗心龙另见 [随从注册表](../lib/game/content.ts)。以下列出普通 CardID；这 68 张的金色 CardID 均为对应普通 CardID 加 `_G`。表内整理原始文案的换行与空白，保留数值、对象、时限和金色重复语义。

审计前，66 张烛台候选全部只接入身份和基础关键词，独有文字均为 `partial`。本轮在 [时空扭曲规则映射](../lib/game/timewarp.ts) 接入其中 28 张：小型 12 张、大型 16 张。诗心龙为既有完整规则；其 [永久保留专项](../tests/dragon-combat-persistence.test.ts) 本次已运行，20 项通过。其余 38 张烛台候选及跳蛙骑士保留为部分支持，共 39 张。

本轮接入的 28 张已通过 `npm run test:timewarp` 的 70 项专项回归；诗心龙另有 20 项既有回归通过。测试入口为 [招募专项][recruit]、[战斗专项][combat] 和 [支持门禁专项][support]；普通/金色、触发次数、满手、共享池、玩家/AI、永久写回、幽灵隔离及存档边界按所涉及的机制验证。生成快照仍保持不变；获取入口的完整性门禁不等于其余 39 张已经实现。

## 可玩门禁

- 完整来源注册表保留全部 66 张，继续用于数据校验、原画和旧存档读取。
- 新产生的烛台发现候选必须经过 `FULLY_SUPPORTED_TIMEWARP_CARD_IDS` 和 `effectSupport === "complete"` 校验，再进行种族过滤和确定性抽取。未完成规则的卡不进入发现候选；满手、候选不足和 AI 选择仍走共享发现路径。
- 跳蛙骑士缺少亡语传播时，其来源饰品 `BG35_MagicItem_870`（跳蛙骑士肖像）不能进入新局饰品候选。诗心龙及其来源饰品 `BG32_MagicItem_364` 保留。
- 存档结构及内容版本继续兼容 v52。既有实体保留属性、身份、池所有权；载入时刷新时空扭曲支持标记及秘书次数文案。旧存档已有的跳蛙待选报价可恢复，新的生成入口仍禁止它。门禁不把历史部分支持实体误记为已完成规则。

## 战斗实现复核要点

1. **触发与向量分开。** 钩尾、佩吉、合唱鱼人和劫掠者的金色是两次完整触发；地卜师的金色是宝石升级翻倍、获得数量仍为 1。数值最终相同不代表触发链相同。
2. **永久与本场分开。** 黏冻大肚怪、帝国之手、滑油机器人、食尸卡布拉和狂棍野猪人要求显式永久写回；小野猪与暮喉龙牌面未写永久，其战斗增益仅在适用的诗心龙等规则下保留。新增实现不能用一次战斗临时 `buff` 来宣称覆盖永久效果。
3. **事件对象不能替换。** 受攻击与受伤不同；成功复生与普通召唤不同；友方死亡与亡语触发不同；吞食对象、购买对象和获得攻击力的目标都须使用原事件对象。圣盾吸收不是受伤。
4. **重复数量不能去重。** 飓风机甲和跳蛙骑士的多份同源亡语必须表示数量；当前学习亡语辅助函数按来源去重，不能直接承担这两个机制。
5. **共享池与生成复制分开。** 获取池随从保留真实归池账本；战斗召唤、亡灵造物、伙伴和对手快照复制不能伪造普通池所有权。满手、满场分别决定入手和召唤，不能用其中一个失败阻止另一个。
