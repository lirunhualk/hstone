## 为什么模型调用又停止

先出现 4 次 ECONNRESET，执行器等待旧请求结算、冷却后发起一次只读健康探测，HTTP 200 后恢复后续新局调用。随后推理接口出现 8 次 HTTP 402，属于冻结协议中不允许自动恢复的拒绝类型；模型调用关闭，所有剩余游戏仍完整结束。HTTP 451 没有复发。

当时模型列表仍为 HTTP 200；HTTP 402 可能涉及额度或计费，账户余额未直接核实。TypeSafe 的[官方计费说明](https://typesafe.ai/legal/mca)说明额度不足时可能拒绝生成输出；本报告不声称已经确认账户余额，也不包含充值或新增付费操作。

另有 3 个应急选择动作、1 次决策上限、202 次循环回退、56 次输入超限回退和 1 次无区分排序回退；非法动作与过期响应均为 0。这些收尾属于冻结接入策略，完整保留，clean=false，promotionAccepted=false。决策记录中的 circuit 回退次数与直接关闭模型续跑的对局数是不同计数，不能据前者为 0 认定没有全局熔断。
