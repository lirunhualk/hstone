# 卡牌效果完整度清单

本清单对应固定数据版本 `battlegrounds-36.0.3-247416-v52`。卡面数据来自仓库内的 build 247416 快照；“完整”只表示普通/金色规则及关键边界已经进入引擎和测试，不以仅有属性、种族或基础关键词冒充完整。

## 当前结论

- 普通酒馆池随从：237/237 张完整。
- 七星随从：12/12 张完整；普通对局中仅由效果生成且不占共享池，“诺甘农的秘密”事件则会为兼容本局种族的七星随从各加入 5 份共享池副本，并开放 7 级酒馆、刷新和三连发现。
- 酒馆法术：65/65 张完整。
- 此前的三个酒馆法术边界已经收口：`BG30_804` 稳健异变可把 6 星目标变为兼容本局种族的随机 7 星随从；`BG30_802` 冒牌的智慧之球包含完整 7 星有用刷新页面；`EBG_Spell_037` 身份揭晓从本项目全部可在中局安全切换的已实现英雄技能中发现 3 个，并重置新技能的状态。
