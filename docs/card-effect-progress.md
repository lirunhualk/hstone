# 卡牌效果完整度清单

本清单对应固定数据版本 `battlegrounds-36.0.3-247416-v25`。卡面数据来自仓库内的 build 247416 快照；“完整”只表示普通/金色规则及关键边界已经进入引擎和测试，不以仅有属性、种族或基础关键词冒充完整。

## 当前结论

- 随从：237 张中 140 张完整、97 张部分支持。
- 酒馆法术：65 张均可玩，其中 63 张完整、2 张部分支持。
- 酒馆法术的两个受限近似：
  - `EBG_Spell_037` 身份揭晓：当前只发现 4 个已完整支持的本地英雄技能。
  - `BG30_802` 冒牌的智慧之球：已实现 1 至 6 星范围的有用刷新，尚缺偶发 7 星页面；未知服务器权重使用可复现的本地随机。
- 完整度的可执行依据是 `lib/game/content.ts` 中的随从白名单、`TavernSpellDefinition.effectSupport`，以及 `tests/live-content.test.ts`、`tests/tavern-spells.test.ts` 的数量断言。

## v25 新完成

- `BG34_926` 无情的女王护卫：战吼、亡语和每次进击都会自动施放“女王的命令”；普通版每个触发点施放一次，金色版施放两次。
- 布莱恩会重复战吼，提图斯会重复亡语，风怒会让每次实际攻击分别触发进击；各层重复都结算完整的一次或两次自动施法。
- 每次“女王的命令”先使所有友方随从获得 +2/+2，再额外使友方纳迦获得 +2/+2；当前酒馆法术额外属性分别计入每个增益脉冲，招募和战斗中的酒馆法术响应也会逐次触发。
- 战斗自动施法与属性变化写入结构化回放事件，幽灵对战不会把战斗临时变化或触发结果写回已淘汰玩家。
