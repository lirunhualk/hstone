# 真实酒馆战棋体验对齐路线图

本项目只学习与单机酒馆战棋本身有关的规则、操作和视觉反馈。游戏运行时不访问 Bilibili，也不收集视频或玩家数据；视频只用于人工观察真实玩家能看到、能操作的客户端体验。

以下结论于 2026-07-30 复核。卡牌规则和数值仍以仓库固定的官方补丁及 HearthstoneJSON 快照为准，视频不能替代官方数据。

## 已对齐且应保留

- 商店、手牌和战场之间的拖放，战场插位和换位。
- Surface 触控与手写笔抬牌预览、边缘限制和宽松落点。
- 卡牌大图检查：鼠标悬停约 120ms、键盘聚焦或 Surface 长按会在源卡旁展示高清原画、当前属性和完整效果文字；移出、开始拖拽、点击其他区域或按 Escape 后关闭，长按松手不会误打出卡牌。
- 磁力、定向法术、塑造法术、鲜血宝石和冻结商店。
- 招募操作反馈：购买会按真实报价先显示金币或生命消耗，再把真实卡面飞入手牌；出售会缩入鲍勃并延后显示实际出售金币；刷新会扫过并替换整行报价；升本会播放星章爆光，折扣、零费和升本返金都按实际结算显示；三连会以真实金色卡面居中锻造。连续操作会按先进先出顺序播放，失败操作不会误播；演出不写入存档，并为“减少动态效果”保留静态状态提示。
- 逐事件战斗回放：攻击目标、伤害、剩余生命、圣盾、阵亡、召唤和英雄伤害。
- 7 名 AI 的确定性运营策略，以及只读取本人上次交手阵容的公平侦察。

## 后续实现顺序

1. **可交互的对手侧栏**
   招募阶段提前保存下一位对手并突出显示。点击玩家行只展示该玩家身份、上轮结果和本人最后一次亲眼见到的阵容，不读取对方当前隐藏战队。

2. **战斗中保留手牌**
   战斗阶段显示缩小且不可操作的手牌，只收起商店，方便观察手牌触发和下一回合资源。

3. **真实目标位移与命中反馈**
   使用攻击者和目标卡牌的实际屏幕坐标，播放蓄力、冲刺、碰撞、回弹；随后依次播放圣盾爆裂、伤害数字、阵亡消散和英雄受击。

4. **连续酒馆桌面布局**
   桌面端把商店、战队、英雄和手牌组织为一块连续棋盘；排名使用窄轨，详情改为悬浮抽屉。小屏和 Surface 触控布局继续单独适配。

5. **酒馆控件继续精修**
   升级星章、刷新扫场和实际资源跳字已经接入；下一步把升级、刷新、冻结改为更接近原版的带费用徽章图标控件，并补冰霜扫过和音效。当前刷新扫场方向是为了本地清晰度设计，视频只足以确认整行报价被替换，不能声称逐帧一致。

6. **发现与抉择演出**
   三张完整卡牌在棋盘中央扇形展开，选择后飞入手牌；保留现有键盘焦点约束和无倒计时流程。三连锻造目前使用清晰的本地金卡聚焦演出，待获得足够视频证据后再校准最初三张卡合并的具体时序。

7. **英雄身份纵切**
   最后再接入开局英雄选择、头像、基础护甲和官方英雄技能。英雄数据与效果必须逐项核对官方来源并加入存档迁移，不能从视频画面推断。

每一批完成后都应同时补行为测试、浏览器交互验收和 README 完整度说明，避免只改外观却破坏单机规则或触控操作。
