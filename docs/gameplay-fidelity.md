# 真实酒馆战棋体验对齐路线图

本项目只学习与单机酒馆战棋本身有关的规则、操作和视觉反馈。游戏运行时不访问 Bilibili，也不收集视频或玩家数据；视频只用于人工观察真实玩家能看到、能操作的客户端体验。

以下结论于 2026-08-04 复核。卡牌规则和数值仍以仓库固定的官方补丁及 HearthstoneJSON 快照为准，视频不能替代官方数据。

## 已对齐且应保留

### 交互与操作

- 商店、手牌和战场之间的拖放，战场插位和换位。
- Surface 触控与手写笔抬牌预览、边缘限制和宽松落点。
- 卡牌大图检查：鼠标悬停约 120ms、键盘聚焦或 Surface 长按会在源卡旁展示高清原画、当前属性和完整效果文字；移出、开始拖拽、点击其他区域或按 Escape 后关闭，长按松手不会误打出卡牌。
- 磁力、定向法术、塑造法术、鲜血宝石和冻结商店。

### 招募阶段演出

- 鲜血宝石逐颗演出：手牌原始宝石、测绘员额外施放和鲁古格转投按引擎真实因果顺序分别播放目标高亮、该步卡面属性、跳字与爆裂；播放期间招募操作锁定，最后一颗才与最终规则状态汇合。食客抉择使用真实选项原画、键盘焦点和无倒计时锁定。
- 招募操作反馈：购买会按真实报价先显示金币或生命消耗，再把真实卡面飞入手牌（`shop-to-hand` cardMove + `is-receiving-purchase` CSS）；出售会缩入鲍勃并延后显示实际出售金币（`board-to-bob` cardMove + `tavern-keeper-receive` CSS）；刷新会扫过并替换整行报价（`shop-refresh-sweep` 820ms）；升本会播放星章爆光（`tavern-tier-burst` 940ms），折扣、零费和升本返金都按实际结算显示；三连会以真实金色卡面居中锻造（`triple` 事件 + 1500ms 独立播放窗口）。连续操作按先进先出顺序播放，失败操作不会误播；演出不写入存档，并为"减少动态效果"保留静态状态提示。
- 冻结冰霜扫过动画（`frost-sweep` 900ms）。
- 商店报价替换动画（`shop-offer-materialize` 520ms）。
- 新卡牌飞入动画（`generated-card-arrival` 620ms）。
- 资源增减跳字动画（`recruit-resource-delta` 900ms，含金币和生命的独立样式）。
- 磁力/抉择/鲜血宝石目标的合法落点脉冲动画。

### 战斗阶段演出

- 战斗中保留手牌：战斗阶段手牌缩小至 62% 原始大小、72% 透明度、不可操作（`game.css:6402-6431`），方便观察手牌触发和下一回合资源。商店降为半透明（`opacity:0.32, brightness:0.42`）而非完全消失。
- 完整攻击动画系统（`game.css:6526-6624`）：
  - **蓄力**：`card-attack-charge`（520ms）— 使用 CSS 变量 `--charge-x`/`--charge-y` 计算屏幕坐标位移，附带金色辉光 `drop-shadow`
  - **碰撞**：`card-attack-collision`（360ms）— 目标闪烁白金色闪光 `box-shadow` + `brightness(1.8)`
  - **回弹**：`card-attack-rebound`（280ms）— 反向弹回原位
  - **受击**：`card-hit`（220ms）— 生命值面板红色高亮
  - 敌我双方攻击器有独立方向动画（`card-attack-enemy`）
- 圣盾爆裂动画：`shield-burst`（560ms）— 金色光环扩散 + 亮度炸裂 + `card-hit` 生命值面板红色高亮
- 伤害跳字动画：`combat-damage-pop`（620ms）— 红色标签底部弹出、放大、上浮、淡出
- 死亡消散动画：`card-death-dissolve`（720ms ease forwards）— 随从淡出，伴彩色碎片粒子散开（`death-fragment-scatter`）
- 属性变化微动：被增益时 ATK/HP 数字短时放大高亮（`stat-pop` 260ms）
- 战斗触发标签：增益（`combat-buff-label`）、减益（`combat-debuff-label`）、召唤（`combat-summon-label`）、战斗开始（`combat-start-of-combat-label`）、复仇（`combat-avenge-label`）、触发（`combat-trigger-label`），均带弹出动画
- 随从状态 CSS 类：`is-combat-actor`（金色光环）、`is-combat-target`（红色光环）、`is-combat-buff-target`（青色光环提升）、`is-combat-debuff-target`（紫色光环）
- 英雄受击动画：`hero-damage-flash`（620ms）
- 磁力融合动画：`magnetic-fuse`（480ms）— 蓝色光环扩散 + brightness burst + scale 回弹
- 商店卡牌周期性光扫（`shop-shine-sweep` 4.2s）+ 卡牌等级星标微光（`tier-star-glimmer` 3.6s）
- 手牌卡牌 hover 抬升发光（teal border + translateY -4px + scale 1.03）
- 战斗面板红调背景光（combat phase 红色径向渐变 + border overlay）
- 战斗 VS 分隔线（金色渐变横线）

### 全局系统

- 逐事件战斗回放：攻击目标、伤害、剩余生命、圣盾、阵亡、召唤和英雄伤害。
- 战斗 intro 转场（`combat-start-intro`）：显示回合数、对阵玩家姓名、幽灵标记。
- 7 名 AI 的确定性运营策略，以及只读取本人上次交手阵容的公平侦察。
- 可交互的对手侧栏：自己保持青蓝标记，招募阶段用红色发光框提前标出固定的下一对手，淘汰玩家显示骷髅；鼠标、触控或键盘可打开公开身份、上一轮结果与本人最后一次亲眼见到的开战阵容。未交手时明确显示"阵容未知"，历史阵容带所见回合，并且战斗回放结束前不会提前揭晓已预结算的战果。
- 16 名被动英雄 + 204 件饰品（98 件次级 + 106 件强效）已接入。

## 后续实现顺序

1. **英雄护甲档位**（已部分完成）
   英雄池 90+ 名英雄均有独立护甲值（`hero-powers.ts`），本局选择后自动分配。帕奇维克额外生命已接入。后续如需动态护甲档位调整（根据 MMR/补丁变化），需接入官方护甲数据源。

2. **英雄主动技能**
   当前 16 项技能均为被动（可自动结算）。大厨曲奇、贸易大王等英雄的主动技能需要新 UI 控件和交互流程。

3. **AI 策略持续迭代**
   见 `docs/ai-learning-roadmap.md`：坐标搜索阶段 2 已建立基础设施但尚未有候选通过门禁（303 训练因 draw 被否决）。后续需在新的 304 区间注册训练，并在留出种子上通过成对部署席位评测。

4. **音效系统**（已明确不需要）
   不做。

5. **移动端竖屏布局**（540px 断点已添加）
   已为 <540px 竖屏添加 grid 重排（shop → board → hand → side），HUD 压缩，卡牌缩小。Surface 触控和桌面布局不变。后续如需继续缩窄到 360px 可添加 `<360px` 断点。

6. **三连锻造时序校准**
   当前使用本地金卡聚焦演出。待获得足够的官方三连逐帧视频证据后，校准最初三张普通卡合并为金卡的具体时序和粒子效果。

7. **英雄主动技能**
   当前 16 项技能均为被动。大厨曲奇、贸易大王等英雄的主动技能需要新 UI 控件和交互流程。
