# 真实酒馆战棋体验对齐路线图

本项目只学习与单机酒馆战棋本身有关的规则、操作和视觉反馈。游戏运行时不访问 Bilibili，也不收集视频或玩家数据；视频只用于人工观察真实玩家能看到、能操作的客户端体验。

以下结论于 2026-08-07 复核。卡牌规则和数值仍以仓库固定的官方补丁及 HearthstoneJSON 快照为准，视频不能替代官方数据。

分阶段战斗伤害上限以暴雪的 [31.2 补丁说明](https://hearthstone.blizzard.com/en-gb/news/24163459/31-2-patch-notes) 为规则依据：单人战棋第 1–3 回合为 5 点、第 4–7 回合为 10 点、第 8 回合起为 15 点，进入前四后解除。Bilibili 实战只用于校准玩家能看到的提示与回放节奏。

## 已对齐且应保留

### 交互与操作

- 商店、手牌和战场之间的拖放，战场插位和换位。
- Surface 触控与手写笔抬牌预览、边缘限制和宽松落点。
- 卡牌大图检查：鼠标悬停约 120ms、键盘聚焦或 Surface 长按会在源卡旁展示高清原画、当前属性和完整效果文字；移出、开始拖拽、点击其他区域或按 Escape 后关闭，长按松手不会误打出卡牌。
- 磁力、定向法术、塑造法术、鲜血宝石和冻结商店。

### 招募阶段演出

- 开局英雄选择：四名真实英雄候选在蓝黑暗场中逐张入场，鼠标、键盘焦点与 Surface 触控使用绿色合法选择轮廓。点击后立即且只保存一次真实选择，展示层再播放“所选英雄聚焦 → 其余候选退场 → 所选英雄居中 → 八名玩家英雄列阵”；演出可跳过且不写入存档，刷新页面不会重新选择或重新分配 AI 英雄。“减少动态效果”会保留静态确认并把两段演出缩短到近即时。原版线上倒计时与锁定槽不纳入单机模式。
- 饰品商店仪式：第 6/9 回合的四个候选先在木质面板中伴随蓝白闪光揭示；神秘魔方继续使用两个免费替换候选。点击候选只写入客户端预选并显示绿色轮廓，不调用引擎、不扣金币；必须再按一次“确认”，且未选择或金币不足时确认保持禁用。确认接受后才执行并保存一次真实 `RESOLVE_INTERACTION`，所选真实卡面在酒馆中央获得展示后缩入对应的小型/大型饰品 HUD 槽；同次结算产生的发现、目标或招募反馈会等落槽结束后再出现。“隐藏/显示”保留原候选顺序、预选和交互锁，Escape、键盘、触控、跳过及“减少动态效果”均可用。展示状态不写存档：确认前刷新恢复同一待选候选，确认后刷新不会重播或重复扣费。
- 发现选择闭环：随从、酒馆法术与暗月奖品使用真实候选卡面、持续绿色合法轮廓和无倒计时选择；“隐藏/显示”只用于查看当前酒馆、战队与手牌，候选快照及待选择状态不变，招募操作仍锁定。点击后立即且只执行一次真实 `RESOLVE_INTERACTION` 并保存结果，瞬时展示层再播放“选中聚焦与金币粒子 → 未选候选退场 → 酒馆重新显现 → 实际奖励卡缩小飞向手牌”。展示层保存旧候选卡面快照，连续发现会等上一段结束后再揭示；同次结算产生的三连演出延后到奖励落位之后。满手烧毁、磁力、变形和普崔塞德组件选择依据已接受的下一状态决定是否存在手牌奖励，绝不把不存在的实例飞向手牌。演出可跳过、不写入存档；刷新直接恢复已结算状态，“减少动态效果”仍保留选中与落位静态确认。
- 战斗返回酒馆：玩家在完整回放后点击“继续招募”，客户端立即且只执行一次 `CONTINUE` 并保存下一回合；视觉层再按 `curtain → roundBanner → shopReveal → goldRefill` 播放战场收束、紫金“招募阶段”横幅、冻结保留/新报价整行显现及金币逐格补充。转场期间延后回合开始三连、待选择交互和战斗奖励提示；可跳过，刷新页面则直接显示已保存的招募状态，不重复回合开始效果。“减少动态效果”会把整段缩短到近即时静态提示。
- 鲜血宝石逐颗演出：手牌原始宝石、测绘员额外施放和鲁古格转投按引擎真实因果顺序分别播放目标高亮、该步卡面属性、跳字与爆裂；播放期间招募操作锁定，最后一颗才与最终规则状态汇合。食客抉择使用真实选项原画、键盘焦点和无倒计时锁定。
- 酒馆法术与塑造法术施放闭环：鼠标、键盘、Surface 触控及拖放入口最终共用同一施放回调；只有已接受的引擎动作才创建不入存档的 `cardLift → spellRelease → effectResolve` 客户端快照。定向施法在抬牌和释放阶段用目标施放前快照遮住已经结算的实时牌面，命中时随局部金紫脉冲退场并揭示新属性/关键词；无目标施法改为战场范围脉冲。同次施法产生的发现、目标选择和招募反馈延后到演出完成或跳过后再出现。普通本地节奏为 `200 + 260 + 220 = 680ms`，是保守可读性选择而非对正式客户端逐帧时长的声明；“减少动态效果”为 `30 + 40 + 30 = 100ms` 静态确认。token、卡牌 ID、阶段及 revision 共同防止陈旧计时器推进新演出，失败与非法施放不会误播。
- 主动英雄技能激活闭环：伊莉斯·逐星、米尔菲丝·法力风暴、阿莱克丝塔萨、迦拉克隆和堕落的乔治只有在引擎最终接受激活后，才从真实 HUD 技能按钮播放 `sourcePulse → resourceCommit → effectResolve`，依次显示源点充能、实际金币消耗与已使用状态、效果收束。规则结算和存档仍在点击时立即且只执行一次，但技能产生的发现与同次招募反馈会等演出完成后才揭示；跳过会立即交接到已经结算的发现，拒绝、金币不足、等级不足或陈旧回调都不会误播。乔治的酒馆/友方双区域合法目标共用同一可访问操作路径，确认后使用金白能量弧线与金蓝护盾展开来衔接最终持续圣盾层；该颜色与形状是本地可读性设计，不声明为正式客户端逐帧复刻。普通本地节奏为 `240 + 260 + 180 = 680ms`，“减少动态效果”为 `30 + 40 + 30 = 100ms` 静态确认；演出期间招募操作锁定，独立 token、技能 ID、阶段和 revision 防止旧计时器推进新演出。
- 招募操作反馈：购买会按真实报价先显示金币或生命消耗，再把真实卡面飞入手牌（`shop-to-hand`）；打出普通随从会保存真实手牌快照及最终插入位置，播放“抬牌 → 蓝色卡影上升 → 落点爆光 → 最终实体显现”的 `hand-to-board` 900ms 闭环，待落场稳定后才开放战吼目标或下一次操作；旧 `PLAY_MINION`、拖放和点击共用同一派生规则，失败、满场与非随从操作不会误播。出售会缩入鲍勃并延后显示实际出售金币（`board-to-bob`）；刷新会扫过并替换整行报价（`shop-refresh-sweep` 820ms）；升本会播放星章爆光（`tavern-tier-burst` 940ms），折扣、零费和升本返金都按实际结算显示；三连按 `acquireHandoff → forgeImpact → goldenReveal → handArrival` 四阶段串行播放，总时长约 590ms，并将真实金色卡面落到实际手牌槽。连续三连各自进入 FIFO 队列；演出可跳过、不写入存档，并为“减少动态效果”保留约 120ms 的静态确认。
- 冻结冰霜扫过动画（`frost-sweep` 900ms）。
- 商店报价替换动画（`shop-offer-materialize` 520ms）。
- 新卡牌飞入动画（`generated-card-arrival` 620ms）。

## 后续实现顺序

1. **英雄护甲档位**（已完成，单机适用）
   30 名可玩英雄均有独立护甲值（`hero-powers.ts`），本局选择后自动分配。帕奇维克等特殊英雄已有额外修正。动态档位（基于服务器胜率调整）不适用于单机环境，因此护甲系统已满足本项目的游戏体验需求。

2. **英雄主动技能**（规则、交互与激活演出已完成）
   主动英雄技能的点击按钮、动态金币费用徽章、已使用/可用/不可用状态已在 HUD 中接入。需目标技能支持战场目标（teal 脉冲突出 + Escape 取消）、商店目标及乔治的双区域随从目标。玩家、AI、UI 与训练环境通过同一引擎报价和执行路径判断费用及合法性；失败操作不会扣除金币、占用本回合次数或播放成功演出。五项可玩主动技能共用真实技能按钮的源点充能、费用和次数提交、效果收束；会产生发现的技能保留正确来源与标题，并在演出结束后才揭示。迦拉克隆额外实现“确认目标再扣费 → 目标弧线与命中 → 高一级三选一 → 所选卡聚焦 → 原槽位漩涡 → 新卡同槽位显现”，并在共享池无候选、目标陈旧或到达本局等级上限时原子拒绝。AI 会继续升级并冻结未完成的高星链，达到普通 6 星或诺甘农 7 星后恢复正常购买评估。乔治按现行 1 费规则允许酒馆或友方目标，购买后保留圣盾，并把临时圣盾转为永久；AI 先保经济与升本，再保护长期核心和烈毒/剧毒、顺劈、风怒等高价值功能随从。尤朵拉样本仍只用于通用源点反馈，不据此开放其尚未审计的挖掘奖励规则。
