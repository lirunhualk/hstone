# 英雄、符文与系统事件

本文记录本地单人战棋的大厅系统边界。随从、酒馆法术与饰品卡池固定在炉石补丁 `36.0.3`、HearthstoneJSON build `247416`；英雄与异变仍是已经完整接入人类玩家、AI、存档和确定性随机数的受限子集。

这不是炉石正式服当前实时轮换的镜像。文中的候选池、费用和效果以本项目固定构建为准，后续正式服改动不会自动进入本地游戏。

## 一局游戏如何开始

用户界面创建的新对局按以下顺序初始化：

1. 使用本局种子随机确定一个全局系统事件，并让所有八名玩家共享该事件。
2. 按本局开放种族过滤 16 名本地英雄并使用本局种子洗牌：预留前四名作为人类玩家的互不重复候选，再把后七名分别分配给 AI。玩家必须四选一后才能继续操作。
3. 第 6 个招募回合开始时开启“小符文”，即官方机制中的“次级饰品”，从四件中选择并购买一件。
4. 第 9 个招募回合开始时开启“大符文”，即“强效饰品”，同样从四件中选择并购买一件。

本地英雄池共有 16 名，但每局只展示过滤并洗牌后的 4 名；玩家的四个候选与七名 AI 分配共占 11 个互不重复的名额，玩家选定后最终上场的八名英雄同样不会重复。格雷布要求野兽或亡灵至少开放一种，伊瑟拉、齐恩瓦拉和霍格船长分别要求龙、元素和海盗开放；即使这四名全部被过滤，仍有 12 名中立候选，足够完成 11 个唯一名额。饰品需要支付界面标出的铸币；铸币不足时不能确认该选择。

当前 16 项英雄技能全部为被动技能，不需要新增主动技能按钮。英雄专属护甲档位不在这批范围内；除帕奇维克明确增加生命外，所有英雄继续沿用本地统一初始生命与护甲规则。

## 符文系统（饰品）

“小符文”和“大符文”是本地界面用语；对应的炉石官方名称分别是“次级饰品”（Lesser Trinket）和“强效饰品”（Greater Trinket）。每名玩家最多各持有一件；一次性效果在购买时结算，持续型效果从购买后生效并保留到本局结束。固定池共有 204 件单人模式饰品：98 件次级饰品、106 件强效饰品。官网卡牌库返回的另外 9 件 `duosOnly` 饰品不会进入单人候选。

第 6 回合从次级池抽取 4 件，第 9 回合从强效池抽取 4 件，候选互不重复。人类和每名 AI 都按自己的当前战队独立抽取，AI 只能在自己的 4 件中选择买得起且评分最高的一件，不能查看完整池。候选使用本局可序列化随机数，因此相同种子与同一存档可以复现。

本地按用户要求采用比正式服更严格的类型规则：

- 无类型饰品固定权重为 1，并在可用时保证至少出现一件。
- 类型专属饰品只有在玩家战队至少有一个对应类型随从时才有资格；数量为 0 时绝不会出现。
- 专属权重为 `1 + 4 ×（该类型随从数 / 当前战队随从总数）`，因此占比越高，进入四个候选的概率严格越大。
- 双类型饰品取其两个关联类型中当前占比更高的一项；“全部”类型随从会计入本局开放的每个类型。
- 在可用时同时保证至少一件最高占比类型饰品和至少一件费用不高于 2 的饰品；最后将四件重新洗牌，保证条件不会泄漏固定位置。

暴雪 Season 13 的正式规则使用第 6 回合 2 只、第 9 回合 3 只的“进入类型”阈值，超过阈值后不会继续增权，并允许部分未进入类型的饰品以减费形式出现。上述“零数量硬排除、按占比连续增权”是本项目明确采用的本地规则，不会冒充正式服服务器权重。

四件已经从 36.0.3 当前池移出的旧饰品仍保留只读定义，确保旧本地存档可继续：次级/强效科多兽皮袋、宁神蜡烛和魔幻蘑菇。它们不会进入任何新局候选。

当前 204 件在池饰品都已经接入可购买、可结算、可供 AI 使用且可存档恢复的运行路径，而不是只展示卡面占位。饰品直接产生的法术、暗月奖品、伙伴和时间扭曲随从会保留固定构建中的实体、属性、类型与基础关键词；其中由饰品间接生成的复杂随从，其尚未被本地随从引擎支持的卡面子效果会明确标记为 `partial`。普崔塞德标签是唯一的数据源近似：公开的固定构建只给出了自定义亡灵入口，没有暴雪服务器端的两个组件池成员表，因此本地使用当前已完整支持的普通亡灵，按战斗组件与功能组件拆成两个稳定池，并仍然执行三选一、合成、酒馆等级上限和归还共享池规则。

“点金术”（Goldenizer）是一张 0 费系统法术，只能选择一个**友方战场随从**并将其变为金色。它不计入酒馆法术的购买、施放或联动次数。若发放时手牌已满，奖励会进入待发队列，在手牌出现空位后补发，不会覆盖或丢弃已有手牌。

## 系统事件（异变）

本地"系统事件"对应炉石官方的"异变"（Anomaly）概念：新对局在英雄选择前随机抽取一个事件，同一事件对全体玩家生效，并在大厅选择界面公开。本地当前已启用 **11 个**已完整实现且能与饰品系统共同运行的事件：

| 系统事件 | 本地效果 |
| --- | --- |
| 点金箭 | 在第 3、6、9……个招募回合开始时，为每名仍存活的玩家发放一张"点金箭"。 |
| 完美炼金术 | 每名玩家开局获得一张"点金术"。 |
| 金钱大战 | 每名玩家以 10 枚铸币开始第一个招募回合。 |
| 讲究的沙漏 | 所有玩家以酒馆等级 2 开始赛局。 |
| 阿曼苏尔的节制 | 所有玩家以酒馆等级 3 和 9 枚铸币开始赛局。 |
| 座无虚席 | 旅店始终保持 7 个卡牌位（6 个随从 + 1 个法术），不随等级变化。 |
| 泰坦爪钩 | 每回合购买的**第一个**随从免费；消耗掉的资格下一回合重置。 |
| 买一送一 | 每回合购买的第一个随从额外获得一张无池副本，不计入原本的法术计数。 |
| 艾蜜特斯的谨慎 | 未花费的金币保留到下一回合；若保留 5 枚以上，额外获得 1 枚金币。 |
| 不退款就捣蛋 | 开局 1 枚金币；随从售价固定 1 金币；出售随从获得 0 金币；升级酒馆多减 2 枚。 |
| 弥米伦发条竞技场 | 无法手动支付金币升级酒馆；酒馆每 2 个招募回合自动升级一次。 |
| 诺甘农的秘密 | 可升级至酒馆等级 7；所有玩家 +10 护甲；战役等级 7 随从加入共享池。 |
| 点亮道路 | 每成功手动刷新 2 次后获得 1 枚金 币（加入下回合）。 |
| 最后时刻 | 在战斗中首次受到致命伤害时将其抵销，并在下回合获得 11 枚金币。 |
| 立即布阵 | 开局时获得 3 个不同的酒馆等级 1 随从加入手牌。 |
| 斥候荣耀 | 开局时场上有一张有耐心的斥候（`BG24_715`）。 |
| 精灵精英 | 旅店只会提供与当前酒馆等级相同的随从。 |
| 流水线 | 每第 2 个回合结束时，获得最左边随从的一张无附魔非金卡副本。 |
| 界域校准 | 每个回合开始时获得一个数量最多的随从类型的随机随从（第 2 回合解锁）。 |
| 黄金竞技场 | 全部酒馆随从皆为金卡；不再获得三合一奖励。 |
| 虚假塑像 | 只需要 2 个随从即可合成金卡；不再获得三合一奖励，改为获得 1 枚金币。 |

“点金箭”（Golden Arrow）是一张 0 费系统法术，只能选择一个**当前酒馆中的随从**并将其变为金色；它不能作用于友方战场随从，也不计入酒馆法术的购买、施放或联动次数。这里的“每 3 个回合”被本地明确解释为每 3 个招募回合发放一次，并在该招募回合开始时触发。它与作用于友方随从的“点金术”（Goldenizer）是两张不同的牌。

系统事件产生的牌同样支持满手牌待发队列。事件选择、英雄和饰品选项、随机友方增益目标都使用可序列化的本局随机数状态，以保证相同存档继续后得到一致结果。

## 旧存档兼容

`v39` 及更早、尚未包含大厅系统的旧存档按中立模式继续运行，不会在读档时突然要求选择英雄，也不会追发第 6 或第 9 回合已经错过的饰品，更不会为进行中的旧对局补抽系统事件。其兼容默认值为：大厅系统关闭、无系统事件、无已选英雄、无饰品及相关计数。

从当前用户界面新建的对局会启用完整大厅流程；新流程的英雄、饰品、事件和待发系统法术状态都会随存档保存。已经包含大厅系统的 `v40` 存档升级到当前内容版本时会保留这些状态。这一边界既避免改变更早旧局的结果，也让原有的独立机制测试可以继续使用中立开局。
