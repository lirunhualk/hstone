# 星港战阵

一款在本机运行的单人自动战棋游戏：你与 7 名 AI 同场竞技，没有回合倒计时，只有你点击“结束回合”后才会进入战斗。

游戏采用原创名称、单位和科幻视觉，只复现自动战棋的核心玩法结构。

## 在 Surface 上启动

最简单的方式是双击仓库根目录中的 `start-game.cmd`。脚本会启动游戏并在浏览器打开：

<http://localhost:3000/>

也可以在 PowerShell 中手动运行：

```powershell
npm install
npm run dev
```

按 `Ctrl+C` 可以关闭本地游戏服务。

## 已实现玩法

- 1 名玩家与 7 名 AI，所有角色初始 40 点生命。
- 每回合 3 到 10 枚金币，不会自动结束回合。
- 购买、出售、刷新、冻结、基地升级和阵列换位。
- 36 个原创单位，包含 6 个等级和多个阵营。
- 共享单位池、三连合成金色单位、永久强化。
- 守卫、护盾、入场效果、毁灭召唤等战斗能力。
- 自动配对、幽灵对战、战斗日志、核心伤害、淘汰和最终排名。
- 7 名 AI 会根据战力、升级节奏、协同和三连机会做决策。
- 每次操作自动保存到本机浏览器，刷新页面可以继续。
- 可随时重开，不需要联网、登录或账号。

## 操作方式

1. 点击补给站中的单位查看详情，再点击“购买”。
2. 点击手牌单位，再点击空阵位，或使用详情区的“部署到阵列”。
3. 点击阵列单位可以调整位置或出售。
4. 准备完成后点击右上角“结束回合”。
5. 查看战斗与战报后点击“继续整备”。

所有核心操作都支持鼠标和 Surface 触控。
