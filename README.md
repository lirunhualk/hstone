# 酒馆战棋 · 本地单机版

一款可在本机运行的单人酒馆战棋：你与 7 名 AI 同场竞技，没有回合倒计时，只有你点击“结束回合”后才会进入战斗。

当前随从与酒馆法术数据已于北京时间 2026-07-29 复核，固定在正式服仍在运行的炉石补丁 `36.0.3`、HearthstoneJSON build `247416`。普通酒馆池包含 237 张单人模式 1 至 6 星随从和 65 张单人模式 1 至 6 星酒馆法术；双人专属与只能特殊获取的 7 星卡不会进入普通刷新。每局从十个普通种族中确定性开放五个，随从与法术的双种族、关联种族都会按真实卡面保留。暴雪公布的 36.2 与第 14 赛季要到北京时间 2026-08-05 才上线，因此不会把尚未实装的预览池提前混入当前游戏。

## 在 Surface 上启动

双击仓库根目录中的 `start-game.cmd`。脚本会检查依赖、缓存首屏酒馆卡图，然后在浏览器打开：

<http://localhost:3000/>

也可以在 PowerShell 中手动运行：

```powershell
npm install
npm run assets:sync
npm run dev
```

按 `Ctrl+C` 可以关闭本地游戏服务。卡图完成缓存后可离线显示；没有缓存的卡会依次尝试 HearthstoneJSON 在线原画和文字回退，不会阻止游戏运行。`start-game.cmd` 只预取首屏，避免 237 张随从让首次启动长时间等待；需要完整离线卡图时单独运行一次 `npm run assets:sync`。

## 已实现玩法

- 1 名玩家与 7 名 AI，所有角色初始 40 点生命。
- 第一回合 3 枚金币，随后按回合增长至默认上限 10；酒馆法术可以提供额外金币、下回合金币或提高上限。游戏不会自动结束回合。
- 36.0.3 的 237 张当前单人普通酒馆随从、十种族、双种族和每局五种族轮换。
- 当前随从展示数量、升级基础费用和共享随从数量。每次刷新会在正常随从之外额外提供 1 张不高于当前等级的酒馆法术，并像正式服一样与随从混排在同一商店行。
- 固定快照完整记录当前 65 张普通酒馆法术；其中 41 张已经接入完整可玩规则，覆盖全部当前 1 至 3 级法术。它们使用真实名称、费用、中文说明、CardID、关联种族和原画进入独立共享法术池；普通法术按费用扣金币，“拼命发掘”改为支付不能致死的生命值，购买后进入普通手牌，施放后消耗且不能三连。
- 购买、出售、刷新、冻结、酒馆升级和随从换位；冻结后商店会显示持续冰霜边框、冷色卡面与明确状态，进入下回合时同时保留原有随从和酒馆法术并自动解冻。
- 商店随从或酒馆法术拖到手牌购买、手牌随从拖到战场上场、定向法术拖到发光随从施放、无目标法术拖到战场施放、场上随从拖动换位或拖到酒馆出售；同时保留点击操作。
- 已接入的法术覆盖发现/获取随从、偷取酒馆随从、单体与全场增益、强化当前或后续酒馆随从、免费刷新、提高金币上限、下回合额外金币和战斗内临时增益等规则；新增“主厨甄选”“搜寻时光”“位面望远镜”“自负”“稳健异变”“时间管理”“累叠雪崩”和“鲜血宝石弹幕”的完整目标、选择、变形、出售、跨回合及战斗结果结算。7 名 AI 会从同一法术池购买并使用。
- 关联种族的酒馆法术只会在对应种族开放的对局中进入共享池；“搜寻时光”发现的牌会显示本回合锁定并在下回合解锁，“时间管理”会打开无倒计时、可键盘操作的二选一弹层。
- 鲜血宝石使用真实 `BG20_GEM` 原画和独立法术手牌：可拖到任意友方随从，也可先选中再点击发光目标；施放时会显示目标高亮、宝石爆裂和 `+攻击/+生命` 跳字。宝石数值按玩家本局成长动态读取，AI 也会使用。
- “剃刀沼泽地卜师”会通过战吼获取 2 张鲜血宝石，“晾膘的游客”出售时获取 2 张，“野猪预言者”会在使用其他野猪人后获取宝石，“暗膘爵士乐手”会永久提高本局宝石生命增益；普通、金色、布莱恩倍增和 10 张手牌上限均按同一规则结算。
- 7 张当前磁力随从都能正常上场或拖到合法随从上吸附；拖动时宿主位置保持稳定，满场仍可吸附，科技元素体和义肢假手会识别各自的双种族目标，点击与键盘操作也有同等入口，吸附后的卡面能力与属性贡献可在详情中回看。
- 共享随从池、三连合成金色随从、打出金色随从后获得“三连奖励”，并从下一酒馆等级的三个候选中发现一张（六级封顶）。
- 需要主动选择的战吼会暂停其他操作并高亮合法目标；“浪荡水手”支持真实的友方目标选择，“猎食的虎鲨”支持野兽发现。
- “废铁残械”会先让你选择一个已有的友方机械，再从当前酒馆等级以内的三个真实机械候选中发现一张并立即吸附；金色版本、布莱恩倍增、满手牌、共享池立即归还和 AI 自动选择均按同一套规则结算。
- “报废废铁回收机”会在战斗中通过亡语从共享池随机获取一张不高于你当前酒馆等级的磁力机械；金色版本、提图斯·瑞文戴尔倍增、满手牌、即时三连、AI 与幽灵对战均按同一套规则逐次结算，获得的牌会保留到下一招募阶段。
- “移动投影仪”的进击会在每次实际攻击时触发，从共享池随机获取不高于你当前酒馆等级的磁力机械；普通版本每次获取 1 张，金色版本获取 2 张，风怒会逐次触发，满手牌、即时三连、AI 与幽灵对战沿用同一套结算。
- “贪睡的援护巨龙”会在每次实际攻击时使当时位于它右侧的随从获得战斗内 +2/+2；金色版本为 +4/+4，风怒每一击都会按伤亡和召唤后的当前站位重新寻找右邻。回放会用青绿色高亮、数值跳字和更新后的卡面属性展示这次增益。
- “飞行专家”的进击会从手牌复制并召唤攻击力最高的随从，且仅存在于本场战斗；金色版本会选择两张不同的最高攻击力随从，满场不会预留未来阵位，风怒每一击都会重新从仍保持不变的手牌召唤新副本，玩家与 AI 使用同一规则。回放会显示真实插入位置和“仅本场”标记。
- “辛多雷直射手”的每次进击会在造成伤害前移除当前目标的复生与嘲讽；风怒第二击会按移除后的嘲讽状态重新选择目标，金色版本不会错误地重复同一次移除。回放会更新目标卡面并以紫色标记被移除的关键词。
- 嘲讽、圣盾、复生、烈毒、剧毒、风怒和顺劈等基础关键词。
- 愤怒编织者、偏折机器人、布莱恩·铜须、提图斯·瑞文戴尔、坎格尔的学徒和巨狼戈德林的当前卡面规则。
- 自动配对、幽灵对战、逐事件战斗回放、战斗日志、英雄伤害、淘汰和最终排名。
- 战斗回放会依次高亮攻击者与目标，支持 1 倍、2 倍速度和跳过；胜负与继续按钮只在播放完成后出现。
- 7 名 AI 会根据战力、升级节奏、协同、三连机会、磁力目标、酒馆法术价值和合法施法目标做决策。
- 每次操作自动保存到本机浏览器，刷新页面可以继续。
- 可随时重开，不需要登录或账号。

所有 237 张随从都使用当前名称、星级、属性、种族、中文说明和真实 CardID 原画。当前有 46 张随从的完整规则已由引擎覆盖，包括首批鲜血宝石获取、使用与成长链，“时空船长钩尾”的酒馆法术触发，多种当前亡语召唤物、战吼增益、战斗开始效果、全场伤害、特殊出售价格、首批主动目标和发现效果，以及 6 张完整磁力随从、“废铁残械”的目标发现吸附链、“报废废铁回收机”的战斗亡语获取、“移动投影仪”的逐次进击获取、“贪睡的援护巨龙”的动态右邻增益、“飞行专家”的临时手牌召唤、“辛多雷直射手”的目标关键词移除与废铁枪骑士的吸附后增益；第 7 张磁力随从“附魔哨卫”已经能吸附，但其塑造法术光环仍会如实标为部分支持。其余复杂卡先结算基础属性和已支持关键词，详情面板会明确提示“专属文字效果仍在逐张适配”，不会把未实现效果冒充为已实现。规则完整度使用显式白名单维护，局部实现不会再被误报成完整。

暂未完整复刻的主要内容是尚未开放规则的 4 至 6 级酒馆法术、其余鲜血宝石联动随从、塑造法术、英雄技能替换、其他尚未适配的进击与磁力牌生成效果、更多主动目标与发现效果，以及原版级别的战斗位移、粒子和音效。全部 65 张法术的数据和卡面字段已经保留在固定快照中；规则未完整的牌不会提前混入商店。

## 操作方式

1. 将商店里的随从或矩形酒馆法术拖到手牌区域购买，也可以点击卡牌后使用“购买”按钮；两者都会占用普通手牌位。
2. 将手牌随从拖到战场的发光插入位置上场。
3. 将定向酒馆法术拖到发光的合法随从施放；卡面写“一个随从”的牌可同时选择战场或酒馆目标，写“友方”的牌只允许战场目标。无目标法术可拖到战场区域，或选中后点击“施放法术”。非法落点不会消耗手牌，按 `Escape` 可取消选择。
4. 磁力随从既可拖到空阵位作为普通随从上场，也可直接拖到发光的合法随从上吸附；选中磁力牌后再点击发光目标同样有效。
5. 将手牌中的鲜血宝石拖到任意友方随从上使用；也可以先点宝石，再点发光随从。拖到空白处会安全返回手牌，按 `Escape` 可取消选择。
6. 打出三连合成的金色随从后，点击手牌中的“三连奖励”，再从中央三个真实候选中选择一张。
7. 打出需要目标的随从后，点击战场上发光的合法目标完成战吼；“废铁残械”选定机械后还会打开三选一发现，选择的机械会立即吸附，不会进入手牌。
8. 横向拖动场上随从调整攻击顺序。
9. 将场上随从拖到鲍勃的酒馆区域出售并获得 1 枚金币。
10. 准备完成后点击右上角“结束回合”。
11. 战斗会按事件顺序播放；可切换 1 倍、2 倍速度或跳过，结束后点击“继续招募”。

所有核心操作都支持鼠标和 Surface 触控。玩家的已支持选择类效果会保留为可恢复的待处理状态；7 名 AI 使用同一规则并自动选择。尚未实现的选择类效果会继续显示适配提示。

## 常用命令

```powershell
npm run dev              # 启动本地游戏
npm run assets:sync      # 下载或补齐全部随从与法术原画
npm run data:bg:check    # 离线校验固定的 237 随从 + 65 法术快照
npm run data:bg:generate # 从固定 build 下载并重建快照
npm test                 # 运行数据与规则引擎测试
npm run lint             # 检查代码
npm run typecheck        # 检查 TypeScript 类型
npm run build            # 生成生产构建
npm run check            # 依次执行全部检查
```

数据生成器固定使用：

```text
https://api.hearthstonejson.com/v1/247416/zhCN/cards.json
SHA-256: 5E48186C2E1702B474088958978D560026A6CDC3990F181CAB790D42A7727013
```

它会分别硬校验随从与酒馆法术的原始活跃数、双人模式排除数、单人池数量、各星级分布和 36.0.3 补丁哨兵，避免 `latest` 在未来版本上线后静默漂移。详细筛选规则见 `lib/game/generated/README.md`。
