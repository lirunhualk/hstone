# 酒馆战棋 · 本地单机版

一款可在本机运行的单人酒馆战棋：你与 7 名 AI 同场竞技，没有回合倒计时，只有你点击“结束回合”后才会进入战斗。

当前随从与酒馆法术数据已于北京时间 2026-07-29 复核，固定在正式服仍在运行的炉石补丁 `36.0.3`、HearthstoneJSON build `247416`。普通酒馆池包含 237 张单人模式 1 至 6 星随从和 65 张单人模式 1 至 6 星酒馆法术；双人专属与只能特殊获取的 7 星卡不会进入普通刷新。每局从十个普通种族中确定性开放五个，随从与法术的双种族、关联种族都会按真实卡面保留。暴雪公布的 36.2 与第 14 赛季要到北京时间 2026-08-05 才上线，因此不会把尚未实装的预览池提前混入当前游戏。

## 在 Surface 上启动

双击仓库根目录中的 `start-game.cmd`。脚本会检查依赖、缓存首屏酒馆卡图，然后在浏览器打开：

<http://localhost:3000/>

也可以在 PowerShell 中手动运行：

```powershell
npm install
npm run assets:sync
npm run dev
```

按 `Ctrl+C` 可以关闭本地游戏服务。卡图完成缓存后可离线显示；没有缓存的卡会依次尝试 HearthstoneJSON 在线原画和文字回退，不会阻止游戏运行。`start-game.cmd` 只预取首屏，避免 237 张随从让首次启动长时间等待；需要完整离线卡图时单独运行一次 `npm run assets:sync`。

## 已实现玩法

- 1 名玩家与 7 名 AI，所有角色初始 40 点生命。
- 第一回合 3 枚金币，随后按回合增长至默认上限 10；酒馆法术可以提供额外金币、下回合金币或提高上限。游戏不会自动结束回合。
- 36.0.3 的 237 张当前单人普通酒馆随从、十种族、双种族和每局五种族轮换。
- 当前随从展示数量、升级基础费用和共享随从数量。每次刷新会在正常随从之外额外提供 1 张不高于当前等级的酒馆法术，并像正式服一样与随从混排在同一商店行。
- 固定快照中的 65 张普通酒馆法术已全部接入可玩规则；1 至 6 星分别为 8、6、16、16、14、5 张。它们使用真实名称、费用、中文说明、CardID、关联种族和原画进入独立共享法术池；普通法术按费用扣金币，“拼命发掘”改为支付不能致死的生命值，购买后进入普通手牌，施放后消耗且不能三连。
- 购买、出售、刷新、冻结、酒馆升级和随从换位；冻结后商店会显示持续冰霜边框、冷色卡面与明确状态，进入下回合时同时保留原有随从和酒馆法术并自动解冻。
- 商店随从或酒馆法术拖到手牌购买、手牌随从拖到战场上场、定向法术拖到发光随从施放、无目标法术拖到战场施放、场上随从拖动换位或拖到酒馆出售；同时保留点击操作。手牌中当前合法可打出的随从、酒馆法术、塑造法术和鲜血宝石会持续显示与真实对局相近的绿色轮廓，无需依赖鼠标悬停；拿起卡牌后会放大为可读卡面，鼠标保持原抓取点，Surface 触控和手写笔则把卡牌抬到指尖上方，并自动限制在屏幕边缘内。
- 已接入的法术覆盖发现/获取随从、偷取酒馆随从、单体与全场增益、强化当前或后续酒馆随从、免费刷新、提高金币上限、下回合额外金币和战斗内临时增益等规则；新增“主厨甄选”“搜寻时光”“位面望远镜”“自负”“稳健异变”“时间管理”“累叠雪崩”和“鲜血宝石弹幕”的完整目标、选择、变形、出售、跨回合及战斗结果结算。7 名 AI 会从同一法术池购买并使用。
- 关联种族的酒馆法术只会在对应种族开放的对局中进入共享池；“搜寻时光”发现的牌会显示本回合锁定并在下回合解锁，“时间管理”会打开无倒计时、可键盘操作的二选一弹层。
- 4 级法术已完整接入：克隆螺号、甲虫恩泽、恶鳞套餐、查抄宝石、寒热骤变、乘借东风、惊扰墓穴、燃焰、奥术吸收、艾欧娜尔的眷顾及原有六张法术均使用真实目标、共享池、跨回合状态和 AI 结算。甲虫会在战斗有空位时补入并把未召唤数量保留到以后战斗；惊扰墓穴会先完成入场效果再死亡并触发亡语，三连可清除死亡预言。
- 5 级法术已全部接入：护甲储备、优势压制、宰割、腐化糕点、点金之触、顶尖好酒、预订遗体、猎头招聘、圣洁庇护、诺兹多姆的子嗣、黄金狂潮、女王的命令、祈请吞噬者、身份揭晓。
- 6 级法术已全部接入：“冒牌的智慧之球”会让之后两次手动刷新变成有用刷新并继续支付正常刷新费用，可复制当前战队、提供组成三连所需的副本或刷新出整页传说随从等页面；“大地母亲之眼”只可将友方 4 级或以下非金色随从变为金色；“哈缪尔遗失的法杖”会用选中随从的类型刷新整个酒馆。智慧之球会先取共享池中的真实副本，池外生成的报价只有被玩家获得后才成为可归还池中的一份；哈缪尔则严格受共享池剩余数量限制。AI、冻结、拖放目标和存档恢复使用同一套规则。

- “身份揭晓”只会从 4 个已完整支持的受限英雄技能候选中发现：资深调酒师、洞察未来、永远绽放、老树新芽。这是本地实现的受限候选池，并非完整官方英雄技能池。

暂未完整复刻的主要内容是完整官方英雄技能池、其余鲜血宝石联动随从、疾涛吉他手以外纳迦的自动塑造法术光环、其他尚未适配的进击与磁力牌生成效果、更多主动目标与发现效果，以及原版级别的战斗位移、粒子和音效。“冒牌的智慧之球”已在本项目 1 至 6 星随从范围内实现公开确认和当前可复核的有用刷新类型；其偶发的 7 星随从结果尚未接入。暴雪没有公开当前服务器的完整候选权重，因此未知权重使用确定性随机，不会伪称为精确服务器参数。

## 操作方式

1. 将商店里的随从或矩形酒馆法术拖到手牌区域购买，也可以点击卡牌后使用“购买”按钮；两者都会占用普通手牌位。
2. 将手牌随从拖到战场的发光插入位置上场。
3. 将定向酒馆法术或塑造法术拖到发光的合法随从施放；酒馆法术卡面写“一个随从”时可同时选择战场或酒馆目标，写“友方”时只允许战场目标，塑造法术只选择友方随从。无目标法术可拖到战场区域，或选中后点击施放。非法落点不会消耗手牌并会提示已返回，按 `Escape` 可取消选择。
4. 磁力随从既可拖到空阵位作为普通随从上场，也可直接拖到发光的合法随从上吸附；选中磁力牌后再点击发光目标同样有效。
5. 将手牌中的鲜血宝石拖到任意友方随从上使用；也可以先点宝石，再点发光随从。拖到空白处会安全返回手牌，按 `Escape` 可取消选择。
6. 打出三连合成的金色随从后，点击手牌中的“三连奖励”，再从中央三个真实候选中选择一张。
7. 打出需要目标的随从后，点击战场上发光的合法目标完成战吼；“废铁残械”选定机械后还会打开三选一发现，选择的机械会立即吸附，不会进入手牌。
8. 横向拖动场上随从调整攻击顺序。
9. 将场上随从拖到鲍勃的酒馆区域出售并获得 1 枚金币。
10. 准备完成后点击右上角“结束回合”。
11. 战斗会按事件顺序播放；可切换 1 倍、2 倍速度或跳过，结束后点击“继续招募”。

所有核心操作都支持鼠标和 Surface 触控。玩家的已支持选择类效果会保留为可恢复的待处理状态；7 名 AI 使用同一规则并自动选择。尚未实现的选择类效果会继续显示适配提示。

## 常用命令

```powershell
npm run dev              # 启动本地游戏
npm run assets:sync      # 下载或补齐全部随从、法术与已支持英雄技能原画
npm run data:bg:check    # 离线校验固定的 237 随从 + 65 法术快照
npm run data:bg:generate # 从固定 build 下载并重建快照
npm test                 # 运行数据与规则引擎测试
npm run lint             # 检查代码
npm run typecheck        # 检查 TypeScript 类型
npm run build            # 生成生产构建
npm run check            # 依次执行全部检查
```
