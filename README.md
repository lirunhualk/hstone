# 经典酒馆战棋 · 单机版

一款在本机运行的单人酒馆战棋：你与 7 名 AI 同场竞技，没有回合倒计时，只有你点击“结束回合”后才会进入战斗。

本项目使用 36 张辨识度较高的真实经典随从名称、原画和招牌技能。它是固定的“经典混合怀旧卡池”，并不对应某一个实时补丁；这样可以避免随官方轮换而频繁改变，也更方便熟悉老随从的玩家辨认。

## 在 Surface 上启动

双击仓库根目录中的 `start-game.cmd`。脚本会检查依赖和本地卡图缓存，然后在浏览器打开：

<http://localhost:3000/>

也可以在 PowerShell 中手动运行：

```powershell
npm install
npm run assets:sync
npm run dev
```

按 `Ctrl+C` 可以关闭本地游戏服务。卡图完成首次缓存后，后续游玩不依赖网络；若图片同步失败，页面会依次尝试在线原画和文字回退，不会阻止游戏启动。

## 已实现玩法

- 1 名玩家与 7 名 AI，所有角色初始 40 点生命。
- 每回合 3 到 10 枚金币，不会自动结束回合。
- 购买、出售、刷新、冻结、酒馆升级和随从换位。
- 36 张经典怀旧随从，每个星级 6 张，包含野兽、机械、恶魔、鱼人、龙、海盗和中立。
- 共享随从池、三连合成金色随从、永久强化。
- 嘲讽、圣盾、复生、剧毒、风怒、顺劈、战吼、亡语、光环和回合结束效果。
- 铜须、瑞文戴尔、光牙、爆爆机器人、瘟疫鼠群、偏折机器人、灵魂杂耍者等招牌触发。
- 自动配对、幽灵对战、战斗日志、英雄伤害、淘汰和最终排名。
- 7 名 AI 会根据战力、升级节奏、协同和三连机会做决策。
- 每次操作自动保存到本机浏览器，刷新页面可以继续。
- 可随时重开，不需要登录或账号。

为了适配单人触控操作，需要选择目标的战吼会自动在符合条件的友方随从中随机选择。卡池没有加入“磁力”等尚未完整实现的随从，避免卡牌说明与实际结算不一致。

## 常用命令

```powershell
npm run dev         # 启动本地游戏
npm run assets:sync # 下载或补齐本地随从原画
npm test            # 运行规则引擎测试
npm run lint        # 检查代码
npm run typecheck   # 检查 TypeScript 类型
npm run build       # 生成生产构建
npm run check       # 依次执行全部检查
```

## 操作方式

1. 点击酒馆中的随从查看详情，再点击“购买”。
2. 点击手牌随从，再点击空位，或使用详情区的“部署到战场”。
3. 点击场上随从可以调整位置或出售。
4. 准备完成后点击右上角“结束回合”。
5. 查看战斗与战报后点击“继续招募”。

所有核心操作都支持鼠标和 Surface 触控。
