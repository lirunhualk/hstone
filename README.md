# 酒馆战棋 · 本地单机版

一款可在本机运行的单人酒馆战棋：你与 7 名 AI 同场竞技，没有回合倒计时，只有你点击“结束回合”后才会进入战斗。

当前随从数据固定在 2026-07-27 正式服仍在运行的炉石补丁 `36.0.3`、HearthstoneJSON build `247416`。普通酒馆池包含 237 张单人模式 1 至 6 星随从；29 张双人专属随从和 12 张只能特殊获取的 7 星随从不会进入刷新。每局从十个普通种族中确定性开放五个，双种族与关联种族会按真实卡面保留。

## 在 Surface 上启动

双击仓库根目录中的 `start-game.cmd`。脚本会检查依赖、缓存首屏酒馆卡图，然后在浏览器打开：

<http://localhost:3000/>

也可以在 PowerShell 中手动运行：

```powershell
npm install
npm run assets:sync
npm run dev
```

按 `Ctrl+C` 可以关闭本地游戏服务。卡图完成缓存后可离线显示；没有缓存的卡会依次尝试 HearthstoneJSON 在线原画和文字回退，不会阻止游戏运行。`start-game.cmd` 只预取首屏，避免 237 张随从让首次启动长时间等待；需要完整离线卡图时单独运行一次 `npm run assets:sync`。

## 已实现玩法

- 1 名玩家与 7 名 AI，所有角色初始 40 点生命。
- 每回合 3 到 10 枚金币，不会自动结束回合。
- 36.0.3 的 237 张当前单人普通酒馆随从、十种族、双种族和每局五种族轮换。
- 当前随从展示数量、升级基础费用和共享随从数量。正式服额外的酒馆法术槽尚未实现，不会用额外随从替代。
- 购买、出售、刷新、冻结、酒馆升级和随从换位。
- 商店拖到手牌购买、手牌拖到战场上场、场上拖动换位、拖到酒馆出售；同时保留点击按钮操作。
- 7 张当前磁力随从都能正常上场或拖到合法随从上吸附；拖动时宿主位置保持稳定，满场仍可吸附，科技元素体和义肢假手会识别各自的双种族目标，点击与键盘操作也有同等入口，吸附后的卡面能力与属性贡献可在详情中回看。
- 共享随从池、三连合成金色随从、打出金色随从后获得“三连奖励”，并从下一酒馆等级的三个候选中发现一张（六级封顶）。
- 需要主动选择的战吼会暂停其他操作并高亮合法目标；“浪荡水手”支持真实的友方目标选择，“猎食的虎鲨”支持野兽发现。
- “废铁残械”会先让你选择一个已有的友方机械，再从当前酒馆等级以内的三个真实机械候选中发现一张并立即吸附；金色版本、布莱恩倍增、满手牌、共享池立即归还和 AI 自动选择均按同一套规则结算。
- 嘲讽、圣盾、复生、烈毒、剧毒、风怒和顺劈等基础关键词。
- 愤怒编织者、偏折机器人、布莱恩·铜须、提图斯·瑞文戴尔、坎格尔的学徒和巨狼戈德林的当前卡面规则。
- 自动配对、幽灵对战、逐事件战斗回放、战斗日志、英雄伤害、淘汰和最终排名。
- 战斗回放会依次高亮攻击者与目标，支持 1 倍、2 倍速度和跳过；胜负与继续按钮只在播放完成后出现。
- 7 名 AI 会根据战力、升级节奏、协同、三连机会和磁力目标做决策。
- 每次操作自动保存到本机浏览器，刷新页面可以继续。
- 可随时重开，不需要登录或账号。

所有 237 张随从都使用当前名称、星级、属性、种族、中文说明和真实 CardID 原画。当前有 36 张卡的完整规则已由引擎覆盖，包括多种当前亡语召唤物、战吼增益、战斗开始效果、全场伤害、特殊出售价格、首批主动目标和发现效果，以及 6 张完整磁力随从、“废铁残械”的目标发现吸附链与废铁枪骑士的吸附后增益；第 7 张磁力随从“附魔哨卫”已经能吸附，但其酒馆法术光环仍会如实标为部分支持。其余复杂卡先结算基础属性和已支持关键词，详情面板会明确提示“专属文字效果仍在逐张适配”，不会把未实现效果冒充为已实现。规则完整度使用显式白名单维护，局部实现不会再被误报成完整。

暂未完整复刻的主要内容是大多数酒馆法术、鲜血宝石、塑造法术、进击、其余生成磁力牌的生态效果、更多主动目标与发现效果，以及原版级别的战斗位移、粒子、音效和数值跳字。它们的数据和卡面仍保留在固定快照中，便于后续逐张实现。

## 操作方式

1. 将酒馆随从拖到手牌区域购买，也可以点击卡牌后使用“购买”按钮。
2. 将手牌拖到战场的发光插入位置上场。
3. 磁力随从既可拖到空阵位作为普通随从上场，也可直接拖到发光的合法随从上吸附；选中磁力牌后再点击发光目标同样有效。
4. 打出三连合成的金色随从后，点击手牌中的“三连奖励”，再从中央三个真实候选中选择一张。
5. 打出需要目标的随从后，点击战场上发光的合法目标完成战吼；“废铁残械”选定机械后还会打开三选一发现，选择的机械会立即吸附，不会进入手牌。
6. 横向拖动场上随从调整攻击顺序。
7. 将场上随从拖到鲍勃的酒馆区域出售并获得 1 枚金币。
8. 准备完成后点击右上角“结束回合”。
9. 战斗会按事件顺序播放；可切换 1 倍、2 倍速度或跳过，结束后点击“继续招募”。

所有核心操作都支持鼠标和 Surface 触控。玩家的已支持选择类效果会保留为可恢复的待处理状态；7 名 AI 使用同一规则并自动选择。尚未实现的选择类效果会继续显示适配提示。

## 常用命令

```powershell
npm run dev              # 启动本地游戏
npm run assets:sync      # 下载或补齐全部随从原画
npm run data:bg:check    # 离线校验固定的 237 张随从快照
npm run data:bg:generate # 从固定 build 下载并重建快照
npm test                 # 运行数据与规则引擎测试
npm run lint             # 检查代码
npm run typecheck        # 检查 TypeScript 类型
npm run build            # 生成生产构建
npm run check            # 依次执行全部检查
```

数据生成器固定使用：

```text
https://api.hearthstonejson.com/v1/247416/zhCN/cards.json
SHA-256: 5E48186C2E1702B474088958978D560026A6CDC3990F181CAB790D42A7727013
```

它会硬校验原始活跃数、双人模式排除数、单人池数量、各星级分布和 36.0.3 补丁哨兵，避免 `latest` 在未来版本上线后静默漂移。详细筛选规则见 `lib/game/generated/README.md`。
